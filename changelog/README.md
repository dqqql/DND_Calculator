# 更新公告（changelog）

放置每次发布的变更说明。使用规范：

- 新增发布时请添加一个以 `vX.Y.md` 命名的文件（例如 `v1.3.md`）。
- 也可以用 `UNRELEASED.md` 存放正在开发但尚未发布的变更。
- 关于 `pack_release.py`：
  - 脚本采用“最小化发行”策略（默认只包含 `index.html`、规则书匹配文件与 `lib/`）；
  - 打包时脚本仍会在预览阶段打印 `changelog/` 中检测到的“最新”公告以便确认，但不会把 `changelog/` 复制到发行包；
  - 若需要把 changelog 一并包含到发行包，可提出需求后将其作为可选参数实现。

条目模板（示例）：

```
## vX.Y — YYYY‑MM‑DD
- 新增：描述新增内容
- 修复：描述修复的 bug
- 调整：描述体验/平衡等调整
```
