# 新春斗兽场（DND 新春怪物角斗场）

简要说明：这是一个静态前端小项目（React + Babel），展示“新春怪物角斗场”的页面和交互演示。

## 快速开始
- 直接在浏览器中打开 `index.html`。
- 或在项目根目录启动临时服务器：
  - Python: `python -m http.server 8000`
  - Node: `npx http-server . -p 8000`

## 依赖
- 已将运行时库放在 `lib/`（包含 React、ReactDOM、Babel），无需额外安装。

## 项目文件
- `index.html` — 入口页面
- `DND新春怪物角斗场.html` — 备用/演示页面
- `lib/` — 本地依赖文件
